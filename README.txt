INSTALLATION SUR LE DÉPÔT joggin-app
1. Conserver le dossier speech tel quel.
2. Remplacer index.html par celui du ZIP.
3. Ajouter ou remplacer manifest.webmanifest, logobicep.png et apple-touch-icon.png.
4. Conserver cloche.wav et decompte_5s.wav; ils ne gênent pas l'app.
5. Attendre le déploiement GitHub Pages, puis recharger la page.
6. Au besoin, supprimer l'ancienne icône iOS et l'ajouter de nouveau.

VOIX
- Les annonces sont assemblées à partir des MP3 individuels dans speech/.
- Pause entre les mots : 0,015 seconde.
- Exemple : courir + 30 + secondes + cycle + 1 + de + 20.
- Un bouton « Tester la voix » se trouve dans Importer / exporter > Réglages.

PROGRAMMES
- Une seule chaîne GP1 contient les 7 jours de musculation et de cardio.
- L'export GX1 contient le suivi, les chronos, les notes et le programme actif.
